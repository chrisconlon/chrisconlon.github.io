Github Page (for .tex files)

Textbooks and readings:
  • Bruce Hansen's Econometrics (authoritative reference)
  • Goff's Causal Inference in Econometrics notes (free; the bridge text)
  • Cunningham's Causal Inference: The Mixtape (free online; assigned reading for the research-design weeks)
  • Wager's Causal Inference: A Statistical Learning Approach (free draft; end of course)
Each session has an in-class workbook (.Rmd): open it in RStudio, reproduce the code from lecture, and work the two short problems.
